# Уголки — мобильная игра для Android

Нативное Android-приложение на Kotlin: классические «Уголки» (шашечная гонка
через доску) с деревянной доской, тремя режимами игры и соперником-ИИ
с тремя уровнями сложности.

## Что внутри

- **Против телефона** — ИИ трёх уровней:
  - лёгкий — почти случайные ходы;
  - средний — жадная тактика;
  - сложный — негамакс с альфа-бета отсечением (до 4 полуходов, бюджет ~0,9 с).
- **Вдвоём на одном экране** — партия за одним телефоном.
- **По Bluetooth** — матч двух телефонов поблизости: один создаёт игру,
  второй присоединяется из списка сопряжённых устройств. Без интернета.
- **Деревянная доска** с плавными анимациями (прыжки перелетают дугой),
  подсветкой допустимых ходов, контуром домов и последнего хода.
- **Звук** ходов и победы (системные тоны, без внешних файлов).
- **Статистика** побед/поражений/ничьих с телефоном.
- **Автосохранение** текущей партии (закрыли приложение — партия восстановится).
- **Правило ходов** переключается: все 8 направлений (по умолчанию, как в
  «диагональных уголках») или только вертикали/горизонтали (классический вариант).

## Правила игры

Реализован классический бытовой вариант «Уголков» (домашняя версия игры
Halma/гальма, распространённая в России):

- Доска 8×8. У каждого по **16 шашек** в квадрате 4×4 в углу: светлые —
  нижний левый, тёмные — верхний правый. Первые ходят светлые.
- За ход перемещается **одна шашка**:
  - шаг на соседнюю пустую клетку;
  - **прыжок** через одну шашку любого цвета на пустую клетку сразу за ней.
    Прыжки можно продолжать **цепочкой** в один ход и остановиться где угодно.
  Взятий нет — шашки не съедают друг друга.
- **Победа** — первым занять все 16 клеток дома соперника.
- **Ничья** — если тёмные завершают перенос своим ответным ходом
  сразу после светлых.
- **Правило 40 ходов** — если после 41-го своего хода у игрока остались шашки
  в собственном доме, он проигрывает (защита от «отсиживания»).
- Игрок, у которого нет допустимых ходов, проигрывает.

> Вариант «только по прямым» соответствует классическим турнирным уголкам
> (без диагоналей), вариант «8 направлений» — самой распространённой
> бытовой версии. Переключается в меню приложения.

## Сборка

Требования:

- **Android Studio** Hedgehog (2023.1.1) или новее (подойдёт и любая более
  свежая — проект стандартный);
- **JDK 17** (входит в Android Studio);
- Android SDK 34 (Android Studio предложит установить автоматически).

Шаги:

1. Распакуйте архив в любую папку.
2. Android Studio → **File → Open…** → выберите папку `Ugolki` (где лежит
   `settings.gradle.kts`).
3. Дождитесь завершения Gradle Sync (первая синхронизация скачивает Gradle 8.4
   и зависимости — нужен интернет).
4. Подключите телефон с включённой **отладкой по USB** или создайте
   эмулятор (Pixel-подобный, API 24+).
5. Нажмите **Run ▶** — приложение установится и запустится.

Сборка APK из консоли: `./gradlew assembleDebug`
(результат — `app/build/outputs/apk/debug/app-debug.apk`).
Для релиза: `./gradlew assembleRelease` (подпись настройте в
`app/build.gradle.kts`).

Параметры: `minSdk = 24` (Android 7.0, ~99% устройств), `targetSdk = 34`,
внешних библиотек нет — только Kotlin и системные API, поэтому проект
собирается быстро и не ломается при обновлении зависимостей.

## Онлайн-сборка (без Android Studio)

Если ставить Android Studio не хочется, APK можно собрать бесплатно
прямо в браузере. В проект уже вложен готовый конфиг
`.github/workflows/android-build.yml` для **GitHub Actions**:

1. Зарегистрируйтесь на [github.com](https://github.com) и создайте
   пустой репозиторий (можно приватный).
2. Загрузите содержимое папки `Ugolki` в репозиторий кнопкой
   **Add file → Upload files** — обязательно вместе со скрытой папкой
   `.github` (на файловом менеджере включите показ скрытых файлов).
3. Откройте вкладку **Actions** — сборка запустится автоматически
   (одна сборка ≈ 3–5 минут).
4. Когда она позеленеет, откройте её и внизу скачайте **Artifacts →
   Ugolki-debug.zip** — внутри готовый `app-debug.apk` для установки
   на телефон.

Debug-APK подписан отладочным ключом и ставится на любой телефон с
разрешением «установка из неизвестных источников»; для Google Play
понадобится своя подпись (`assembleRelease` + keystore).

Альтернативы GitHub Actions:

- **Codemagic** (codemagic.io) — 500 бесплатных минут в месяц, из коробки
  понимает Android/Gradle-проекты;
- **Bitrise** (bitrise.io) — мобильный CI со свободным тарифом;
- **GitLab CI** — если предпочитаете GitLab: тот же скрипт
  `./gradlew assembleDebug` в `.gitlab-ci.yml`;
- **GitHub Codespaces / Gitpod** — облачная IDE в браузере: открываете
  репозиторий, в терминале выполняете `./gradlew assembleDebug` и
  скачиваете APK из файлового дерева.

## Игра по Bluetooth

1. Сопрягите телефоны в настройках Bluetooth (один раз).
2. На первом телефоне: Меню → Режим игры → **По Bluetooth** →
   **Создать игру** — он ждёт соперника.
3. На втором: Меню → Режим игры → По Bluetooth → **Присоединиться к другу** —
   выберите первый телефон в списке.
4. Игра начинается автоматически. Создавший игру играет светлыми и ходит первым.
   На Android 12+ приложение запросит разрешение «Близлежащие устройства» —
   оно нужно только для игры по Bluetooth; офлайн-режимы работают без него.

При обрыве связи партию можно продолжить против телефона одним нажатием.

## Структура проекта

```
Ugolki/
├── settings.gradle.kts, build.gradle.kts, gradle.properties  — конфигурация сборки
├── gradle/wrapper/, gradlew                                   — Gradle wrapper
└── app/src/main/
    ├── AndroidManifest.xml
    ├── java/com/example/ugolki/
    │   ├── MainActivity.kt        — экраны, диалоги, режимы, статистика
    │   ├── game/Game.kt           — правила: доска, ходы, прыжки, победа
    │   ├── game/Ai.kt             — соперник: 3 уровня сложности
    │   ├── ui/BoardView.kt        — деревянная доска, анимации, подсказки
    │   ├── bt/BtGame.kt           — матч по Bluetooth (хост/клиент, протокол)
    │   └── util/Sfx.kt, Prefs.kt  — звук; настройки и автосохранение
    └── res/                       — разметка, строки, цвета, иконки
```

Игровая логика (`Game.kt`) — чистый Kotlin без Android-зависимостей:
её удобно дорабатывать и покрывать тестами. Именно эта логика была
предварительно проверена набором из 17 тестов на эталонной реализации
(генерация ходов, цепочки прыжков, победа, ничья, правило 40 ходов).

## Как доработать

- **Изменить количество шашек/дом** — `Game.kt`, блок `init` (заполнение
  `homeLight`/`homeDark`) и проверки `hasWon`.
- **Сила ИИ** — `Ai.kt`: глубина поиска в `searchBest`, весовые коэффициенты
  в `evalBoard`, бюджет времени.
- **Цвета доски** — `BoardView.kt`, блок `init`.
- **Тексты** — `res/values/strings.xml`.
- Перед публикацией в Google Play смените `applicationId`
  (в `app/build.gradle.kts`) с `com.example.ugolki` на свой.

Приятной игры!
